<h1 align="center">WindowShade · 창 가리개</h1>

<p align="center">창 전체를 숨기지 않고, 필요한 부분만 가볍게 가리세요.</p>
<p align="center">macOS 14+ · Apple Silicon · Swift / AppKit</p>

![창의 일부에 반투명 가리개와 불투명 가리개를 놓은 컨셉 이미지](assets/hero.png)

> 위 이미지는 기능을 표현한 컨셉 이미지입니다. 실제 앱 화면은 아닙니다.

아이폰 미러링 화면이 너무 밝거나, 브라우저의 일부를 잠시 가리고 싶을 때 쓰는 메뉴 막대 앱입니다. 가리개는 창을 따라 움직이며 여러 영역을 각각 조절할 수 있습니다.

## 할 수 있는 일

| 기능 | 사용 방식 |
| --- | --- |
| 창에 붙는 가리개 | 아이폰 미러링에는 자동으로 붙고, 다른 앱 창에는 직접 추가할 수 있습니다. |
| 여러 영역 | 같은 창에 가리개를 여러 개 붙이고 위치와 크기를 각각 정합니다. |
| 가리개별 조절 | 어둡기·색·마우스 주변 밝게·클릭 통과·테두리를 따로 설정합니다. 어둡기를 최대로 올리면 완전히 가려집니다. |
| 카메라 반응 | 선택한 가리개만 반응합니다. 반응 거리 안의 다른 사람이 화면을 보거나 다가오면 즉시 검게 가립니다. |
| 손 신호 | 주먹을 1초 보이면 바로 가리고, 손바닥을 1초 보이면 다시 보입니다. 내 손에만 반응합니다. |

화면 위에 반투명 막을 그리는 방식이라 **화면 기록 권한은 필요하지 않습니다.** 카메라 반응 기능을 사용할 때만 카메라 권한을 요청합니다.

## 설치

1. [v1.3.15 릴리스](https://github.com/Harry1757/windowshade/releases/tag/v1.3.15)에서 `WindowShade.zip`을 내려받아 압축을 풉니다.
2. `창 가리개.app`을 **응용 프로그램** 폴더로 옮겨 실행합니다. 앱 창 대신 화면 상단 메뉴 막대에 `◐`가 나타납니다.
3. 이 앱은 회사 개발 인증서를 사용하지 않았습니다. macOS가 첫 실행을 막으면 [Apple 안내](https://support.apple.com/en-us/102445)에 따라 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**에서 직접 확인합니다.

아이폰 미러링 창을 열면 기본 가리개가 붙습니다. 작은 조절 아이콘을 **클릭**해 어둡기를 조절하세요. `⌘⇧D`로 모든 가리개를 잠시 숨기거나 다시 표시할 수 있습니다.

## 원하는 곳만 가리기

메뉴 막대의 `◐`를 클릭하면 바로 고를 수 있습니다.

- **현재 창 전체 가리기**: 맨 앞 창 전체에 가리개를 붙입니다.
- **현재 창 일부만 가리기…**: 가리개를 붙이고 곧바로 영역 편집으로 들어갑니다.
- **창 선택해서 붙이기**: 목록에서 창을 고릅니다. 창을 움직이거나 크기를 바꾸면 가리개가 따라갑니다.
- **떠 있는 가리개 추가**: 창과 무관하게 화면 위의 한 곳을 가립니다.

영역 편집 중에는 가리개를 **끌어서 옮기고, 가장자리·모서리를 당겨 크기를 바꿉니다.** 영역 바로 위에 뜨는 **삭제 · 설정 · 고정** 버튼으로 끝내며, `Return`을 눌러도 고정됩니다. 편집하는 동안 가리개는 반투명해져 뒤의 내용을 보며 맞출 수 있습니다.

<img src="assets/usage-edit.png" alt="영역 편집 중 가리개와 삭제·설정·고정 버튼" width="760">

- 한 창의 여러 곳을 가리려면 가리개 메뉴의 **같은 창에 새 영역 추가**를 반복합니다.
- 모서리 모양은 설정의 **모서리 둥글기**에서 바꿉니다. 기본값 0은 선택선과 가리개 모두 각진 모서리입니다.
- 아이폰 미러링은 **아이폰 화면만 가리기 / 조작부까지 가리기**를 선택할 수 있습니다.

## 카메라 반응 · 실험적 기능

### 시작하기

1. `◐ → 카메라 트래킹 → 나로 지정…`에서 혼자 카메라를 정면으로 보고 본인을 등록합니다.
2. **트래킹 켜기**를 선택한 다음, 반응시킬 가리개에서만 **카메라 반응**을 켭니다. 꺼 둔 가리개는 직접 정한 어둡기를 그대로 유지합니다.
3. 카메라를 끄려면 같은 메뉴에서 **트래킹 끄기**를 누릅니다.

### 언제 가려지나

아래 경우에 **카메라 반응**을 켠 가리개가 즉시 검게 바뀝니다. 감지된 사람이 사라지고 약 2.5초가 지나면 원래 어둡기로 돌아갑니다.

- 반응 거리 안에 있는 다른 사람이 화면 쪽을 봅니다. 다른 사람은 고개가 약 55도까지 비스듬해도 화면을 보는 것으로 칩니다.
- 다른 사람 얼굴이 1초 안에 눈에 띄게 커지거나(다가옴) 정면 쪽으로 돌아옵니다(돌아봄). 아직 화면을 보기 전이라도 먼저 가립니다.
- 얼굴은 안 보이지만 가까운 상반신이 정면으로 감지됩니다.

**반응 거리**는 0.5m~3m 사이에서 미터로 정합니다(기본 1.3m). 이보다 먼 사람은 화면을 봐도 무시합니다. 거리는 화면 속 얼굴·어깨 크기로 어림한 값이라 맥북 내장 카메라 기준의 대략값입니다. 작거나 먼 얼굴도 찾도록 화면을 겹치는 확대 영역으로 나눠 한 번 더 살펴봅니다.

내가 고개를 돌려 얼굴 인식이 흔들리거나 얼굴 없이 몸만 보여도, 직전 3초 동안 내가 있던 자리면 나로 봅니다. 그래서 곁눈질을 하거나 잠깐 딴 곳을 봐도 가려지지 않습니다.

### 손 신호로 바로 가리기

- **주먹을 1초** 보이면 카메라 반응 가리개가 완전히 검게 됩니다.
- **손바닥을 펴서 1초** 보이면 다시 보입니다.
- 1초가 안 되게 잠깐 쥐었다 펴면 반응하지 않습니다. 같은 모양을 계속 들고 있어도 한 번만 반응합니다.

손 신호는 **내 손에만** 반응합니다. 내 얼굴이 보여야 하고, 손목이 내 몸(어깨·팔)의 손목과 겹치면 내 손, 다른 사람 몸의 손목과 겹치면 남의 손으로 봅니다. 팔꿈치가 안 보여 손목이 안 잡히면 내 얼굴 가까이에 크게 찍힌 손을 내 손으로 봅니다. 뒤에 있는 사람의 손은 작게 찍혀 걸러지고, 다른 사람 얼굴에 더 가까운 손도 무시합니다. `◐ → 카메라 트래킹 → 주먹 1초 가리기 · 손바닥 1초 풀기`에서 끌 수 있습니다.

### 미리보기로 보며 조절

`◐ → 카메라 트래킹 → 미리보기로 보며 조절…`을 열면 카메라 영상이 거울처럼 좌우 반전되어 나타나고, 카메라가 무엇을 어떻게 판단하는지 바로 보입니다.

| 표시 | 뜻 |
| --- | --- |
| 초록 네모 | 나 |
| 빨강 네모 | 화면을 보는 다른 사람 → 가림 |
| 주황 네모 | 딴 곳을 보는 다른 사람 |
| 회색 네모 | 반응 거리 밖이라 무시하는 사람 |
| 이름표만 있음 | 얼굴 없이 몸만 보이는 사람 |
| 파랑 원 | 내 손 (예: ✊ 주먹 · 0.6초) |
| 회색 원 | 무시한 다른 사람 손 |

다른 사람 이름표에는 대략의 거리(예: 약 1.2m)가 붙습니다. 가려지는 중이면 영상이 어두워지고, 위쪽 상태 문구에 이유가 나옵니다.

아래 두 눈금은 기준선을 끌면 바로 적용됩니다. 눈금 위 표시는 지금 보이는 사람들의 값을 보여 줍니다.

- **① 본인 인식 기준** (엄격히 ↔ 완만히): 본인인데 가려지면 오른쪽으로, 다른 사람을 나로 착각하면 왼쪽으로 옮깁니다.
- **② 반응 거리** (가까이 ↔ 멀리): 몇 미터 안에 들어온 사람에게 반응할지 정합니다.

미리보기 창은 다른 앱을 쓰는 동안에도 떠 있습니다. 미리보기를 열면서 켠 카메라는 창을 닫으면 꺼집니다.

### 개인정보와 한계

얼굴 비교용 특징은 **이 Mac의 키체인에만 저장**되고 앱을 껐다 켜도 유지됩니다. 영상은 저장하거나 전송하지 않습니다. 머리 모양, 안경, 조명이 바뀌어 인식이 흔들리면 **나로 다시 지정…**을, 초기화하려면 **본인 등록 정보 삭제…**를 사용하세요.

카메라 판단은 완벽하지 않습니다. 다른 사람을 놓치거나 본인으로 잘못 볼 수 있고, 카메라 화면 밖의 사람은 감지하지 못합니다. 바로 옆에 붙어 앉은 사람의 팔까지 안 보이면 그 사람 손이 손 신호로 잡힐 수 있습니다.

## 소스에서 빌드

Xcode 명령줄 도구가 설치된 Mac에서 실행합니다.

```sh
./build.sh
```

완성된 앱과 압축 파일은 `dist/`에 생성됩니다. 빌드는 개인용 임시 서명으로 진행하며 회사 인증서는 사용하지 않습니다.

## 현재 범위

- 앱을 다시 열면 아이폰 미러링용 기본 가리개가 다시 생성됩니다. 직접 추가한 가리개는 아직 저장되지 않습니다.
- 카메라 트래킹은 앱을 열 때마다 직접 켜야 합니다. 등록한 본인 얼굴 정보는 유지됩니다.
- 흐림 효과는 포함하지 않았습니다.
